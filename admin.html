Hinweise

So funktioniert es: Die Links stehen in der Datei links.json im Repository. „Speichern“ schreibt diese Datei über die GitHub-Schnittstelle neu. Danach baut GitHub Pages die Seite neu – nach etwa 1–2 Minuten sind die Änderungen sichtbar.

Sicherheit: Diese Seite ist öffentlich erreichbar, kann ohne gültigen Token aber nichts ändern. Der Token wird nur in diesem Browser gespeichert (bei „merken“ dauerhaft, sonst bis zum Schließen des Tabs) und nur an api.github.com gesendet. Nur auf eigenen Geräten „merken“ anhaken.
